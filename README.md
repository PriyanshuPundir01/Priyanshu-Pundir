An interactive, high-performance developer portfolio showcasing full-stack applications, AI RAG platforms, and secure architectures. Built with modern web standards, cyber-aesthetic micro-animations, and client-side PDF intake generation.

---

## 🌟 Key Features

- **Cyber & Sleek Visual Design**: Custom dark-mode aesthetic with fluid gradients, neon accents, and responsive typography (`Kanit`).
- **Interactive Project Showcase**: Deep dive into 6+ production-grade projects spanning AI/RAG, cybersecurity, banking, and full-stack web platforms with interactive architecture specs.
- **Project Inquiry System**: Client inquiry intake with service selector, editable scopes, and automated on-the-fly PDF receipt dispatch powered by `jsPDF`.
- **Verified Credentials & Resume Viewer**: Embedded interactive modal for resume review and PDF download.
- **Micro-Interactions**: Dynamic magnetic buttons, staggered reveal animations (`Framer Motion`), infinite marquee banners, and smooth viewport transitions.
- **Zero Sensitive Data Leaks**: Fully sanitized, client-side architecture with comprehensive `.gitignore` and `.gitattributes` protecting environment files and temporary build artifacts.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) and `npm` installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/PriyanshuPundir01/Priyanshu-Pundir.git
   cd Priyanshu-Pundir
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
